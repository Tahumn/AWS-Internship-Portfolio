During my internship at **Amazon Web Services Vietnam Company Limited** from **June 22, 2026 to August 15, 2026**, I had the opportunity to study, practice, and apply my academic knowledge to the development and deployment of a practical software system on Amazon Web Services.

I participated in the group project **Cloud Finance Platform – Personal Finance Management System**. The platform supports financial account management, income and expense transactions, budgets, savings goals, financial planning, recurring transactions, receipt recognition using OCR, and an AI-powered financial assistant.

My primary responsibilities involved researching AWS architecture, designing deployment diagrams, containerizing the application, and deploying the system to AWS. I directly participated in configuring Amazon VPC, subnets, route tables, a NAT Gateway, Security Groups, Amazon ECR, ECS Fargate, an Application Load Balancer, Amazon RDS for PostgreSQL, ElastiCache for Redis, Amazon S3, CloudFront, AWS WAF, Secrets Manager, CloudWatch, and Amazon SES.

I also contributed to the CI/CD workflow using GitHub Actions and OpenID Connect, allowing GitHub to authenticate with AWS without storing long-lived access keys. During deployment, I investigated and resolved issues related to Docker images, ECS task definitions, Service Connect, database migrations, CloudFront routing, Google Sign-In, OCR, the Gemini API, and email configuration.

Through these activities, I improved my skills in requirements analysis, architecture design, programming, database administration, containerization, cloud deployment, log analysis, troubleshooting, and technical documentation. I also gained a clearer understanding of the differences between a cost-optimized demonstration architecture and a highly available production architecture.

Regarding my working attitude, I consistently attempted to complete assigned tasks, proactively studied official documentation, recorded deployment issues, and tested multiple approaches to identify suitable solutions. In teamwork, I communicated progress, shared deployment results, and coordinated with other members to synchronize the source code and application features.

### Achievements

During the internship, I achieved the following outcomes:

- Understood the process of analyzing, designing, developing, and deploying a microservices system.
- Learned to design AWS architectures using draw.io and AWS Architecture Icons.
- Deployed backend microservices on Amazon ECS with AWS Fargate.
- Configured internal communication through ECS Service Connect and AWS Cloud Map.
- Deployed Amazon RDS for PostgreSQL with multiple logical databases.
- Used Redis as a job queue between the Notification API and Notification Worker.
- Deployed the frontend through Amazon S3 and Amazon CloudFront.
- Configured an Application Load Balancer, AWS WAF, Secrets Manager, and CloudWatch.
- Established a CI/CD process using GitHub Actions and AWS OIDC.
- Improved my ability to analyze logs and troubleshoot cloud deployment problems.
- Learned how to monitor, estimate, and optimize AWS operating costs.
- Completed architecture documentation, deployment instructions, the Worklog, and the internship Portfolio.

### Limitations and Areas for Improvement

Despite the achieved results, I identified several limitations:

- My experience in designing production architecture and operating high-traffic systems remains limited.
- My time estimation for technical tasks was not always accurate, especially for unpredictable deployment issues.
- At times, I spent too much time testing different solutions before consolidating the evidence and creating a structured troubleshooting plan.
- My technical communication should become more concise, structured, and focused.
- Team responsibilities and progress should be managed more clearly through checklists, issues, or a project board.
- Infrastructure as Code, automated testing, Auto Scaling, and disaster recovery were not fully implemented.
- My AWS cost forecasting skills should be improved through greater use of Cost Explorer and AWS Pricing Calculator.
- Additional security, performance, and load testing is required.

### Improvement Plan

In the future, I plan to:

- Study the AWS Well-Architected Framework and production system design principles.
- Learn Infrastructure as Code using AWS CloudFormation, AWS CDK, or Terraform.
- Add unit, integration, and end-to-end tests to the CI/CD workflow.
- Study ECS Service Auto Scaling, Multi-AZ deployment, backup, and disaster recovery.
- Improve my ability to analyze logs and metrics and configure CloudWatch alarms.
- Improve planning and time-estimation skills.
- Use GitHub Issues or Project Boards to manage team responsibilities more clearly.
- Improve presentation, technical writing, and architectural decision explanation skills.
- Continue optimizing Docker images, ECS resource allocation, and AWS operating costs.

### Overall Assessment

Overall, the internship helped me progress from theoretical AWS knowledge to the ability to build and deploy a practical system. I learned how to work with multiple AWS services, troubleshoot deployment failures, and balance architecture quality, deployability, and operating costs.

I assess that I completed most of my assigned responsibilities successfully and made a positive contribution to the project. However, I still need to improve my planning, communication, testing, infrastructure automation, and production architecture skills to handle larger and more complex systems in the future.
